# US-01 – Load Money into Digital Wallet

## User Story

As a registered user, I want to add money to my digital wallet by entering my Wallet ID and amount, so that I can maintain funds in my digital wallet.

## Acceptance Criteria

- User should be able to log in successfully.
- User should be able to enter the Wallet ID.
- User should be able to enter the amount.
- User should be able to select the Add Money option.
- The system should process the request.
- The system should confirm when money is successfully added.
- The wallet balance should be updated after a successful transaction.

## Expected Behaviour

When the user provides a valid Wallet ID and amount and selects Add Money, the system should process the request and display a successful money-added confirmation.

## Priority

High
