# US-02 – AI Fraud Check

## User Story

As a digital wallet user, I want the system to check a transaction amount using AI, so that I can know whether the transaction appears safe or fraudulent.

## Acceptance Criteria

- User should be able to enter the Wallet ID.
- User should be able to enter the transaction amount.
- User should be able to select the AI Fraud Check option.
- The system should process the entered transaction.
- The system should display the fraud-check result.
- The result should indicate either SAFE or FRAUD.

## Expected Behaviour

When the user provides the required Wallet ID and amount and selects AI Fraud Check, the system should analyze the transaction and display the appropriate result.

## Example

- Amount: 1,000 → SAFE
- Amount: 100,000 → FRAUD

## Priority

High
