# MyBank – User Stories

## Overview

This repository contains user stories prepared for the MyBank / DigiWallet project as part of the Kricon I.T. Solutions Internship Program.

The user stories are based on the MyBank project screenshots provided for Task 5.

## Project Features

The user stories cover:

1. Load Money into Digital Wallet
2. AI Fraud Check

| ID | Feature |

| US-02 | AI Fraud Check |

- `US-01-load-money.md` – User story for loading money into the digital wallet
- `US-02-ai-fraud-check.md` – User story for AI-based fraud checking

## Purpose

The purpose of this repository is to document the functionality shown in the MyBank project screenshots as clear and testable user stories.
